# 위험도 점수와 라벨 해석 기준

## 문서 정보

- 문서 목적: 우리 서비스의 매물 위험도 점수와 라벨을 AI가 일관되게 설명하기 위한 RAG 참고 문서
- 기준 코드: `backend/src/main/java/com/ssafy/home/risk/service/RiskService.java`
- 관련 API: `GET /api/properties/{propertyId}/risk`
- 관련 응답: `RiskResponse`
- 관련 라벨: `SAFE`, `CAUTION`, `DANGER`, `UNKNOWN`
- 주의: 이 문서는 현재 서비스 코드의 위험도 산정 기준을 설명한 내부 기준 문서이며, 법률 자문이나 보증금 반환 보장을 의미하지 않는다.

## 위험도 점수의 의미

위험도 점수는 매물이 전세 계약 관점에서 추가 확인이 필요한 정도를 0점부터 100점까지 표현한 보조 지표이다.

점수가 높을수록 위험 신호가 많거나 강하다는 뜻이다. 점수가 낮다고 해서 전세사기 위험이 없다는 의미는 아니며, 점수가 높다고 해서 반드시 전세사기라고 단정할 수도 없다.

AI는 위험도 점수를 설명할 때 다음 표현을 사용한다.

- 낮은 점수: 현재 서비스 데이터 기준으로 위험 신호가 적은 편
- 중간 점수: 추가 확인이 필요한 요소가 있는 상태
- 높은 점수: 계약 전 권리관계와 보증금 회수 가능성을 우선 확인해야 하는 상태

## 위험도 라벨

위험도 라벨은 점수 구간에 따라 결정된다.

| 라벨 | 한글명 | 점수 구간 | 의미 |
| --- | --- | --- | --- |
| `SAFE` | 안전 | 0점 이상 30점 이하 | 현재 서비스 데이터 기준으로 위험 신호가 낮은 편 |
| `CAUTION` | 주의 | 31점 이상 60점 이하 | 일부 위험 신호가 있어 계약 전 추가 확인 필요 |
| `DANGER` | 위험 | 61점 이상 100점 이하 | 위험 신호가 강하므로 계약 전 우선 검토 필요 |
| `UNKNOWN` | 분석 불가 | 계산 불가 | 비교 데이터가 부족하거나 필수 매물 정보가 없어 충분히 분석하지 못함 |

AI 답변에서는 영어 라벨보다 한글명을 우선 사용한다.

예를 들어 `CAUTION`은 "주의", `DANGER`는 "위험", `UNKNOWN`은 "분석 불가"로 설명한다.

## UNKNOWN 라벨

`UNKNOWN`은 위험이 낮다는 뜻이 아니다. 현재 데이터로 위험도를 충분히 계산하지 못했다는 뜻이다.

다음 경우에 `UNKNOWN`이 반환된다.

- 매물의 면적 정보가 없음
- 보증금 정보가 없음
- 거래 유형 정보가 없음
- 주변 비교 매물이 3개 미만임

주변 비교 매물은 같은 동, 같은 거래 유형, 대상 매물과 비슷한 면적 범위에서 찾는다. 현재 기준으로 대상 면적에서 약 20제곱미터를 뺀 값부터 20제곱미터를 더한 값까지가 비교 범위이다.

AI는 `UNKNOWN`을 설명할 때 다음처럼 안내한다.

- "위험이 없다는 뜻이 아니라, 비교 가능한 데이터가 부족해 분석이 제한된 상태입니다."
- "등기부등본, 확정일자 부여현황, 전입세대 확인서, 보증보험 가능 여부를 별도로 확인해야 합니다."

## 점수 구성 요소

위험도 점수는 다음 요소를 더해서 계산한다.

- 가격 갭 점수
- 신고 점수
- 소유자 검증 패널티

최종 점수는 최대 100점으로 제한된다.

## 가격 갭 점수

가격 갭은 주변 비교 매물의 평균 보증금과 대상 매물의 보증금을 비교해 계산한다.

계산식은 다음과 같다.

```text
priceGapRate = (주변 평균 보증금 - 대상 매물 보증금) / 주변 평균 보증금 * 100
```

현재 서비스 기준에서는 대상 매물의 보증금이 주변 평균보다 많이 낮을수록 가격 갭 점수가 높아진다.

| 가격 갭 비율 | 가격 갭 점수 | 해석 |
| --- | ---: | --- |
| 10% 미만 | 0점 | 주변 평균과 큰 차이가 없는 편 |
| 10% 이상 20% 미만 | 15점 | 주변 평균보다 낮아 추가 확인 필요 |
| 20% 이상 35% 미만 | 30점 | 주변 평균보다 많이 낮아 주의 필요 |
| 35% 이상 | 50점 | 주변 평균보다 매우 낮아 강한 확인 필요 |

AI는 가격 갭을 설명할 때 "싸서 좋다"고만 말하면 안 된다. 주변보다 지나치게 낮은 보증금은 허위매물, 조건 누락, 권리관계 문제, 보증보험 제한 등 추가 확인이 필요한 신호일 수 있다.

## 신고 점수

사용자 신고가 있는 경우 신고 사유별 점수를 더한다.

신고 점수는 최대 40점까지만 반영된다.

| 신고 사유 | 코드 | 점수 |
| --- | --- | ---: |
| 사기 의심 | `FRAUD_SUSPECTED` | 15점 |
| 허위 매물 | `FAKE_LISTING` | 15점 |
| 가격 불일치 | `PRICE_MISMATCH` | 8점 |
| 연락 불가 | `NO_CONTACT` | 8점 |
| 사진 불일치 | `PHOTO_MISMATCH` | 4점 |
| 기타 | `ETC` | 4점 |

AI는 신고 점수를 설명할 때 신고가 곧 사실 확정이라는 식으로 말하면 안 된다. 신고는 사용자 제보 기반의 위험 신호이며, 사실관계 확인이 필요하다고 안내한다.

## 소유자 검증 패널티

매물의 데이터 출처가 `AGENT`이면 소유자 검증 정보가 확인된 것으로 보고 추가 패널티를 주지 않는다.

매물의 데이터 출처가 `PUBLIC`이면 소유자 검증 여부가 확인되지 않은 것으로 보고 10점을 더한다.

| 데이터 출처 | ownerVerified | 패널티 | 해석 |
| --- | --- | ---: | --- |
| `AGENT` | true | 0점 | 현재 데이터 기준으로 소유자 검증 정보가 확인됨 |
| `PUBLIC` | false | 10점 | 현재 데이터 기준으로 소유자 검증 여부가 확인되지 않음 |

AI는 `ownerVerified=false`를 설명할 때 "소유자가 가짜다"라고 단정하면 안 된다. "현재 서비스 데이터에서 소유자 검증 여부가 확인되지 않는다"라고 표현한다.

## 계산 예시

주변 평균 보증금이 3억 원이고 대상 매물 보증금이 2억 8천만 원이면 가격 갭은 약 6.7%이다. 이 경우 가격 갭 점수는 0점이다.

신고가 없고 소유자 검증 정보가 확인된 매물이라면 총점은 0점이며 라벨은 `SAFE`, 한글명은 "안전"이다.

주변 평균 보증금이 3억 원이고 대상 매물 보증금이 2억 2천만 원이면 가격 갭은 약 26.7%이다. 이 경우 가격 갭 점수는 30점이다.

여기에 연락 불가 신고가 1건 있으면 신고 점수 8점이 더해져 총점은 38점이다. 라벨은 `CAUTION`, 한글명은 "주의"이다.

주변 평균 보증금이 3억 원이고 대상 매물 보증금이 1억 5천만 원이면 가격 갭은 50%이다. 이 경우 가격 갭 점수는 50점이다.

여기에 사기 의심 신고 1건이 있으면 15점이 더해지고, 공개 매물이라 소유자 검증 패널티 10점이 더해져 총점은 75점이다. 라벨은 `DANGER`, 한글명은 "위험"이다.

## AI 비교 분석에서의 사용 방식

매물 비교 AI는 위험도 점수를 그대로 총점에 더하지 않는다. 위험도 점수는 높을수록 위험하므로, 비교 분석에서는 안전성 점수로 변환해 사용한다.

```text
위험 안전성 점수 = 100 - 위험도 점수
```

단, 위험도 라벨이 `UNKNOWN`이면 안전성 점수를 50점으로 둔다. 이는 안전하다는 뜻이 아니라, 판단이 불확실하므로 중립 점수로 처리한다는 의미이다.

비교 분석 총점은 생활유형 설문 여부에 따라 다르게 계산된다.

생활유형 설문 결과가 있는 경우:

```text
총점 = 생활 적합도 45% + 위험 안전성 40% + 비용 조건 15%
```

생활유형 설문 결과가 없는 경우:

```text
총점 = 위험 안전성 70% + 비용 조건 30%
```

AI는 비교 총점을 설명할 때 위험도 점수와 비교 총점을 혼동하지 않아야 한다.

- 위험도 점수: 높을수록 위험 신호가 큼
- 비교 총점: 높을수록 비교 목록 안에서 추천 우선순위가 높음

## 응답 필드 해석

`GET /api/properties/{propertyId}/risk` 응답의 주요 필드는 다음과 같다.

| 필드 | 의미 |
| --- | --- |
| `propertyId` | 위험도 분석 대상 매물 ID |
| `label` | 위험도 라벨 |
| `score` | 위험도 점수 |
| `marketPriceAvg` | 주변 비교 매물의 평균 보증금 |
| `priceGapRate` | 주변 평균 대비 대상 매물 보증금 차이 비율 |
| `reportCount` | 해당 매물에 접수된 신고 수 |
| `ownerVerified` | 현재 서비스 데이터 기준 소유자 검증 정보 확인 여부 |

`marketPriceAvg`와 `priceGapRate`는 `UNKNOWN` 상태에서는 없을 수 있다.

## AI 답변 시 표현 원칙

AI는 위험도 관련 답변에서 다음 원칙을 지켜야 한다.

- `SAFE`를 "전세사기 위험이 없다" 또는 "보증금 반환이 보장된다"고 말하지 않는다.
- `CAUTION`은 "계약 금지"가 아니라 "추가 확인 필요"로 설명한다.
- `DANGER`는 "전세사기 확정"이 아니라 "강한 위험 신호가 있으므로 계약 전 우선 확인 필요"로 설명한다.
- `UNKNOWN`은 "안전"이 아니라 "분석 데이터 부족"으로 설명한다.
- 신고는 사실 확정이 아니라 사용자 제보 기반 위험 신호로 설명한다.
- 소유자 검증 미확인은 가짜 임대인이라는 뜻이 아니라, 서비스 데이터에서 검증 여부가 확인되지 않았다는 뜻으로 설명한다.
- 위험도 점수만으로 계약 여부를 단정하지 않고, 등기부등본, 선순위 권리, 확정일자, 전입신고, 보증보험 가능 여부를 함께 확인하도록 안내한다.

## 사용자 질문별 답변 기준

사용자가 "왜 위험 점수가 높아?"라고 물으면 가격 갭, 신고 수와 신고 유형, 소유자 검증 여부를 나누어 설명한다.

사용자가 "주의면 계약하면 안 돼?"라고 물으면 주의는 계약 금지가 아니라 추가 확인이 필요한 상태라고 설명한다.

사용자가 "안전이면 괜찮은 거야?"라고 물으면 현재 서비스 데이터 기준 위험 신호가 낮은 편이지만, 보증금 반환이 보장되는 것은 아니라고 설명한다.

사용자가 "분석 불가가 뭐야?"라고 물으면 면적, 보증금, 거래 유형, 주변 비교 매물 수 같은 분석 데이터가 부족하다는 뜻이라고 설명한다.

사용자가 "전세사기 위험 낮은 순서로 알려줘"라고 물으면 위험도 점수가 낮고 라벨이 안전에 가까운 매물을 우선하되, `UNKNOWN` 매물은 안전하다고 단정하지 않고 별도 확인 대상으로 안내한다.
