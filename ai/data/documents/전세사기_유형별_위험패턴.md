# 전세사기 유형별 위험 패턴 해설

## 1. 깡통전세

### 정의
보증금이 집값(매매가)에 비해 지나치게 높아, 경매 시 보증금 전액을 돌려받지 못하는 상태.

### 위험 공식
```
(선순위 근저당 채권액 + 내 보증금) > 집 매매가 × 70%
```
위 조건이면 위험. 경매 낙찰가는 통상 시세의 70~80%이므로, 선순위 채권이 많을수록 보증금 회수 불가.

### 체크 방법
- 등기부등본 을구에서 근저당 설정금액 확인
- 국토교통부 실거래가 공개시스템에서 최근 매매가 확인
- (근저당 채권최고액 ÷ 1.2) + 내 보증금 < 시세 × 70% 이어야 안전

## 2. 신탁사기

### 정의
집주인이 부동산을 신탁회사에 맡긴 상태에서, 신탁회사 동의 없이 임대차 계약을 체결하는 사기.

### 위험 신호
- 등기부등본 갑구에 **"신탁"** 또는 **"우선수익자"** 등기 존재
- 계약 상대방이 신탁원부 열람을 거부하거나 회피
- 신탁 등기 이후 체결된 임대차 계약은 신탁회사에 대항력 없음

### 피해 구조
신탁 등기된 부동산은 실질 소유권이 신탁회사에 있음.
집주인(위탁자)이 신탁회사 동의 없이 전세 계약 → 경매 시 임차인 보증금 보호 불가.

### 확인 방법
등기부등본 갑구에서 신탁 등기 여부 확인 후,
신탁원부 열람 신청(등기소)하여 임대 동의 여부 확인 필수.

---

## 3. 이중계약 (중복 임대)

### 정의
동일 주택에 여러 임차인과 동시에 계약하여 보증금을 중복 수령하는 사기.

### 위험 신호
- 집주인이 잔금 전 열쇠 전달 거부
- 이사 당일 다른 세입자 짐이 있음
- 공인중개사가 계약서 원본 보관을 고집

### 예방법
- 잔금 지급 직전 현장 방문하여 점유 상태 직접 확인
- 계약서 원본 반드시 임차인이 보관
- 잔금일 당일 등기부등본 재발급하여 새로운 권리 설정 여부 확인

---

## 4. 대리인 사기

### 정의
실제 소유자가 아닌 제3자가 위조된 위임장으로 임대차 계약을 체결하는 사기.

### 위험 신호
- 소유자 본인이 계약 자리에 없고 "대리인"만 참석
- 위임장의 인감도장과 인감증명서가 최근 발급본이 아님
- 신분증 원본 제시를 거부하거나 사진으로만 보여줌

### 필수 확인 사항
- 등기부등본상 소유자와 신분증의 이름/주소 일치 여부
- 위임장에 날인된 인감 = 인감증명서의 인감 일치 여부
- 인감증명서 발급일이 계약일 기준 3개월 이내
- 가능하면 소유자에게 직접 전화로 위임 사실 확인

---

## 5. 선순위 보증금 미고지 (다가구주택)

### 정의
다가구주택에서 이미 다른 세입자들의 보증금이 선순위로 쌓여 있는데,
이를 고지하지 않고 신규 임차인과 계약하는 사기.

### 다가구 vs 다세대 차이
- **다가구**: 단독주택으로 등기, 호수별 등기 없음 → 선순위 보증금 파악 어려움
- **다세대**: 호수별 구분등기 → 개별 권리관계 확인 가능

### 확인 방법
- 확정일자 현황 열람 신청 (주민센터, 임차인 본인만 신청 가능)
- 건물 전체 선순위 보증금 합계 + 내 보증금 < 시세 × 70% 확인
- 임대인에게 전체 임차 현황 서면 제공 요청

---

## 6. 잔금일 권리 설정 사기

### 정의
계약금·중도금 수령 후 잔금일 직전에 근저당을 추가 설정하여
임차인 보증금보다 선순위 채권을 만드는 사기.

### 예방법
- 계약서 특약에 명시: **"잔금 지급 전까지 추가 담보 설정 금지, 위반 시 계약 해제 및 계약금 배액 배상"**
- 잔금 지급 직전(당일 오전) 등기부등본 재발급 확인
- 변경사항 발견 즉시 잔금 지급 중단
