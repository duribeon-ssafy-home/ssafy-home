# 부동산 계약 체크리스트

## 계약 체결 전

- [ ] 등기부등본 직접 열람 (당일 발급)
- [ ] 건축물대장 확인 (위반건축물 여부)
- [ ] 토지이용계획 확인 (재개발/재건축 구역 여부)
- [ ] 실제 소유자와 임대인 동일 여부 확인
- [ ] 대리인 계약 시 위임장 + 소유자 신분증 확인
- [ ] 선순위 근저당·보증금 합계 vs 시세 비교

## 계약서 작성 시

- [ ] 특약사항에 "잔금 전 추가 담보 설정 금지" 명시
- [ ] 특약사항에 "전입신고 및 확정일자 취득 임대인 동의" 명시
- [ ] 계약금 영수증 수령
- [ ] 임대인 신분증 사본 수령

## 잔금일 당일

- [ ] 잔금 지급 직전 등기부등본 재확인
- [ ] 이사 완료 후 전입신고 (당일)
- [ ] 확정일자 부여 (당일)
- [ ] 임대차 계약서 원본 보관

## 입주 후

- [ ] 전세보증보험 가입 (가능한 한 빠르게)
- [ ] 임대차 신고 (의무 대상인 경우)
- [ ] 주택 하자 사진 촬영 및 보관
