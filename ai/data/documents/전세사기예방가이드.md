# 전세사기 예방 가이드

## 계약 전 필수 확인 사항

### 1. 등기부등본 확인
- 계약 당일 직접 발급하여 확인 (인터넷등기소)
- 근저당권, 가압류, 압류 설정 여부 확인
- 소유자와 임대인이 동일인인지 확인
- 공동담보, 신탁 등기 여부 확인

### 2. 전입신고 + 확정일자
- 이사 당일 바로 전입신고 완료
- 주민센터 또는 정부24에서 확정일자 부여받기
- 확정일자: 계약서에 날짜 도장을 받아야 우선변제권 발생

### 3. 위험한 집주인 패턴
- 보증금이 주변 시세보다 지나치게 저렴한 경우
- 소유자가 아닌 대리인과 계약하는 경우
- 계약 후 잔금 전 근저당이 추가 설정되는 경우
- 다가구주택에서 선순위 보증금 총액이 집값을 초과하는 경우

## 전세보증보험 가입

### 가입 조건
- HUG(주택도시보증공사): 전세보증금이 수도권 7억원, 지방 5억원 이하
- SGI서울보증: 보증금 한도 없음 (심사 필요)
- HF한국주택금융공사: 공사 승인 임대인만 가능

### 가입 시기
- 임대차 계약 체결 후 잔금일로부터 1개월 이내 (HUG 기준)
- 가입 시 임대인 동의 불필요

## 계약 후 체크리스트
1. 전입신고 완료 확인 (다음날 효력 발생)
2. 확정일자 날인 확인
3. 전세보증보험 가입 완료
4. 임대차 신고 (보증금 6천만원 초과 또는 월세 30만원 초과 시 의무)
