# 전세보증보험 상품 비교 (2024~2025 기준)

## 상품별 핵심 비교

| 상품 | 가입 한도 | 주요 조건 | 보증료율(연) |
|------|-----------|-----------|-------------|
| HUG 전세보증금반환보증 | 수도권 7억원, 지방 5억원 이하 | 임대차계약 1년 이상, 전입신고·점유·확정일자 필요, 목적물 권리침해 없어야 함 | 0.04%~0.18% |
| SGI서울보증 전세금보장신용보험 | 상품별 약관 확인 필요 | 임대인 동의 없이 가입 가능, 한도·적용대상은 상품 약관 기준 | 약관 기준 별도 확인 |
| HF 전세지킴보증 | 수도권 7억원, 기타 5억원 이하, 주택가액 90% 범위 내 | 2020.4.1 이후 계약, 전입·점유·확정일자, 계약기간 1년 이상 | 0.04%~0.18% |

## HUG 보증료율 상세 (LTV 기준)

| LTV 구간 | 보증료율(연) |
|----------|-------------|
| 70% 이하 | 0.04% |
| 70% 초과 ~ 80% 이하 | 0.11% |
| 80% 초과 ~ 90% 이하 | 0.18% |

## 가입 시기

- HUG: 임대차 계약 체결 후 **잔금일로부터 1개월 이내** (임대인 동의 불필요)
- 가입 전 반드시 등기부등본 확인하여 선순위 권리 파악

## 보증보험 가입 시 확인사항

- [ ] 보증금이 해당 상품 한도 이하인지 확인
- [ ] 전입신고 및 확정일자 취득 여부
- [ ] 주택 선순위 근저당 합계가 보증 가능 범위 내인지 확인
- [ ] 위반건축물 여부 (가입 제한 사유)

## 유의사항

- 기관별 보증료율은 수시 조정 → 가입 시점 공식 홈페이지 확인 필수
- SGI서울보증은 세부 상품별 조건이 상이하므로 약관 직접 확인 필요
