# 등기부등본 읽는 법 — 임차인을 위한 실전 가이드

## 등기부등본 구성

| 구분 | 내용 |
|------|------|
| 표제부 | 부동산 기본 정보 (소재지, 면적, 구조) |
| 갑구 | 소유권 관련 사항 |
| 을구 | 소유권 외 권리 (근저당, 전세권 등) |

---

## 표제부 확인사항

- **소재지**: 계약서상 주소와 일치 여부
- **면적**: 실제 면적과 계약 면적 비교
- **건물 종류**: 다가구/다세대/아파트 여부 (권리관계에 영향)
- **위반건축물 여부**: 건축물대장과 교차 확인 필요

---

## 갑구 — 소유권 확인

### 반드시 확인할 사항

**1. 현재 소유자**
- 최신 순위번호의 소유자 = 계약 상대방인지 확인
- 소유자가 법인이면 법인등기부등본 추가 확인

**2. 위험한 갑구 등기 유형**

| 등기 종류 | 의미 | 위험도 |
|-----------|------|--------|
| 가압류 | 채권자가 소유자 재산 임시 동결 | 높음 |
| 압류 | 세금/채무 미납으로 강제 집행 가능 | 매우 높음 |
| 가처분 | 소유권 분쟁 진행 중 | 매우 높음 |
| 신탁 | 신탁회사로 소유권 이전 | 높음 (별도 확인 필요) |
| 경매개시결정 | 이미 경매 진행 중 | 계약 불가 |

**3. 소유권 이전 빈도**
- 단기간 소유자가 여러 번 바뀐 경우 → 사기 가능성 높음

---

## 을구 — 권리 부담 확인

### 근저당권

**채권최고액의 의미**
- 등기된 금액은 실제 대출의 120~130%로 설정
- 실제 대출액 추정: 채권최고액 ÷ 1.2

**안전 기준 계산**
```
(채권최고액 ÷ 1.2) + 내 보증금 ≤ 시세 × 70%
```

**예시**
- 시세 3억원, 근저당 채권최고액 1억 2천만원, 내 보증금 1억원
- 실제 대출 추정: 1억 2천만원 ÷ 1.2 = 1억원
- 1억원 + 1억원 = 2억원 ≤ 3억원 × 70% = 2억 1천만원 → 안전

### 전세권

- 선순위 전세권이 있으면 해당 전세권자가 우선변제
- 내 보증금보다 선순위 전세권 금액이 크면 위험

### 위험한 을구 등기

| 등기 종류 | 위험 이유 |
|-----------|-----------|
| 근저당 다수 설정 | 선순위 채권 합계 증가 |
| 임차권등기 | 전 임차인 보증금 미반환 상태 |
| 지상권 | 토지 사용 제한 가능 |

---

## 등기부등본 발급 타이밍

| 시점 | 이유 |
|------|------|
| 계약 당일 오전 | 계약 직전 최신 권리관계 확인 |
| 잔금일 당일 오전 | 계약 후 권리 변동 여부 재확인 |
| 전입신고 후 | 내 임차권 반영 여부 확인 |

> **핵심**: 인터넷등기소(iros.go.kr)에서 700원에 즉시 발급. 반드시 계약 당일 직접 발급할 것. 중개사가 보여주는 사본은 신뢰 불가.

---

## 빠른 위험 판별 체크리스트

- [ ] 갑구 소유자 = 계약 상대방 일치
- [ ] 갑구에 가압류/압류/경매개시 없음
- [ ] 갑구에 신탁 등기 없음
- [ ] 을구 근저당 채권최고액 합계 확인
- [ ] (근저당 합계 ÷ 1.2) + 보증금 < 시세 × 70%
- [ ] 임차권등기 없음 (전 세입자 보증금 문제 없음)
