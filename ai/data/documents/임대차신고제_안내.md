# 주택 임대차 신고제 안내 (2025년 기준)

> 계도기간 2025년 5월 31일까지 연장, 2025년 6월 1일 이후 계약분부터 과태료 부과

## 신고 의무 기준

| 항목 | 기준 |
|------|------|
| 의무 신고 대상 | 보증금 6,000만원 초과 **또는** 월세 30만원 초과 |
| 신고 기한 | 계약 체결일로부터 **30일 이내** |
| 신고 의무자 | 임대인 또는 임차인 (공동 신고 원칙, 일방도 가능) |

## 신고 방법

| 방법 | 내용 |
|------|------|
| 방문 신고 | 주택 소재지 관할 주민센터 |
| 온라인 신고 | 부동산거래관리시스템 (rtms.molit.go.kr) |

## 과태료 기준

| 위반 유형 | 과태료 |
|-----------|--------|
| 미신고 또는 지연신고 | 최대 30만원 이하 |
| 거짓 신고 | 최대 100만원 이하 |

## 신고 면제 대상

- 보증금 6,000만원 이하이고 월세 30만원 이하인 계약
- 계약 갱신 시 보증금·월세 변동 없는 경우

## 중요 일정

| 일자 | 내용 |
|------|------|
| 2021년 6월 1일 | 임대차 신고제 시행 |
| 2025년 5월 31일 | 계도기간 종료 |
| **2025년 6월 1일** | **과태료 부과 시작** |

## 확정일자 자동 부여

임대차 신고 완료 시 확정일자 자동 부여 (별도 신청 불필요)
