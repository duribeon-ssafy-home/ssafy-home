# AGENTS.md

## Repository Overview

This repository contains both backend and frontend projects.

- `backend`: Spring Boot backend project
- `frontend`: Vue 3 frontend project

## General Rules

- Before making changes, identify whether the task belongs to `backend`, `frontend`, or both.
- Follow the nearest `AGENTS.md` file in the target directory.
- Do not modify unrelated files.
- Frontend API integration should follow the actual backend response format when backend code is available.
